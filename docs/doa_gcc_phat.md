# DOA GCC-PHAT 检查、修改与验证报告（2026-10-07）

GCC-PHAT 已进入默认生产 RTL 的最终 delay 数据通路：audio_top → doa_square（GCC_PHAT=1）→ doa_gcc_phat → doa_fft512（四次 FFT、四次 IFFT）→ 峰值/Q4 → lag_x、lag_y → 原 direction_track 与 PS angle_of。显示 audio_spectrum 无改动。本文区分 RTL/模块验证与历史上板固件；现有 release 内固件尚未更新为本次版本。

## A. 当前工程原始实现

| 项目 | 源码确认结果 |
|---|---|
| Fs | 48828.125 Hz = 50 MHz / 16 / 64；rtl/i2s_duplex.v 的 div[3] 为 BCLK、div[9] 为 WS |
| 麦克风间距 | README、sw/doa_uart/main.c 规定边长 50 mm 的正方形；不是仅有两个麦克风。四条相邻边用于 DOA，非 70.71 mm 对角线 |
| 帧 | 512 点、四通道、两个 bank，每通道原有 1024×signed16 分布式 RAM |
| 输入 | I2S 24 位 → dc_block → mic_gain → speech_band → v0..v3[23:8]；原 DOA 在 en 读取上一份滤波结果 |
| 搜索 | doa_square 的 MAX_LAG=8，四对 (0,1)、(3,2)、(0,3)、(1,2) 各搜索 -8..8 |
| 相关 | 直接时域 sum a[n]·b[n+lag]，n=8..503，每个延迟 496 个乘积；16×16→signed32，signed48 累加；最大约 496×2^30 < 2^39，48 位安全，无累加饱和或有损截断 |
| 插值 | interpolation/FRAC 状态的三点抛物线：delta=0.5·(left-right)/(left-2·center+right)，Q4 四位小数，即 1/16 sample；最多八次减法得到四舍五入偏移，钳制 ±8 Q4=±0.5 sample |
| 原有效性 | m0 帧能量≥2097152、正峰、非搜索边界；峰须比非邻近峰高至少自身的 1/32；两条平行边差≤1 sample；quality 实质为 0/31，不是连续 VAD 概率 |
| 方位 | 四麦平面方位 angle_of(x,y)=atan2(-x,-y)·180/pi，取整并映射至 0..359°；不用双麦 asin |
| 平滑 | direction_track：延迟矢量长度门限、三点中值、带六位内部小数的 IIR；默认 shift=2，相当于 0.75 old+0.25 new；只在 accepted 时更新 |
| FFT 用途 | audio_spectrum 是自写 512 点 radix-2 定点 FFT，XPM 为存储宏；16 柱显示约 95–6104 Hz。工程没有 xfft IP；既未参与原 DOA，也未参与 PL 降噪 |

**双缓冲握手**：没有独立 frame_done/buffer_sel 端口；en 是样本使能，wr==511 是帧完成事件，bank 是采集 bank，readbank 是计算 bank，state==0 表示能接受一帧；update 是结果事件、valid 是该结果的算法有效性。正常帧完成时 readbank←bank，bank←~bank，同时启动计算。原实现忙时也无条件翻转 bank，只置 overrun，故下一帧会写计算 bank；超时后不仅丢帧，还可能污染当前结果。

**物理范围**：tau_max=0.05/343=145.7726 μs；N_max=0.05×48828.125/343=7.1178025 samples。±8 余量 0.8821975 sample（18.0674 μs），保留 MAX_LAG=8。参数来自现有接线与软件定义；如果实际阵列边长不同，需要用户提供真实安装尺寸，重新评估搜索及方向几何门限。

## B. 发现的问题

| 程度 | 判断与处理 |
|---|---|
| 严重 | 原链路是普通互相关，未满足 GCC-PHAT 升级目标；增加独立运算数据通路 |
| 严重 | 双缓冲超时仍翻转导致读写同 bank；新链路及保留的 legacy 链路均改为忙时丢弃新帧、保持 bank，不覆盖锁定数据 |
| 中等 | 原置信度只检查单通道能量、微小峰差；随机噪声可能给出假峰。新链路检查每对两通道能量、PHAT 峰高度、非邻近峰及峰/平均绝对幅值，invalid 保持结果 |
| 轻微 | DOA 原 en 与 speech_band 输出提交事件不对齐；改为 band_valid，使采集明确消费已完成的四通道输出 |
| 轻微 | 原仿真脚本写死 D: 工具目录；仿真 TCL 使用 XILINX_VIVADO，run_sim.bat 优先现有 PATH 并兼容本机 C: 安装 |
| 无需修改 | ±8 有物理余量；现有 HPF、Q4 抛物线与中值/IIR 已有合理实现；保留采样点数、坐标系及音频输出链路 |

新实现首次综合发现 spectra 虽标注 block，仍退化为 LUTRAM；已经以显式 XPM 双端口 RAM 修正，最终综合使用 5 个 BRAM36。

## D. GCC-PHAT 最终数据流

~~~text
mic0..3 → 原 DC HPF → 增益 → 原四路带通 → band_valid
    ↓
四通道 512 点 A/B 缓冲（计算期间锁定 readbank）
    ↓
独立 DOA FFT 核：依次 FFT0/FFT1/FFT2/FFT3
    ↓
四通道 512 complex-bin BRAM
    ↓
对 (0,1)、(3,2)、(0,3)、(1,2)：Xa × conj(Xb)
    ↓
|G|≈max(|Re|,|Im|)+0.5 min(|Re|,|Im|)
    ↓
Re、Im / (|G|+64) → signed16 Q14
（DC、Nyquist、幅值不足 epsilon 的 bin 置零）
    ↓
同一 DOA 核 IFFT → 取真实相关实部
    ↓
搜索 -8..8（读取 IFFT[(-lag) mod 512] 保留原延迟符号）
    ↓
三点抛物线 Q4 → 能量/峰高/旁瓣/峰平均比
    ↓
两条平行边一致性 → 平均为 X/Y Q4
    ↓
valid + update；invalid 保持上次有效 raw delay
    ↓
原 direction_track：几何门限 → 中值 → IIR（accepted 才更新）
    ↓
原 PS atan2(-x,-y) → 原始/跟踪方位 → 原显示与波束目标

clean_l → 原 audio_spectrum → 16 柱 HDMI（独立并行，无 DOA 仲裁）
~~~

**为什么不调度显示 FFT**：原 audio_spectrum 控制器绑定自身采集/选 bin/显示发布，没有外部 transform 请求、复数输入、频谱读出或 inverse 接口。为了共享它，需要新增采集缓存、复数缓存、方向/显示仲裁、返回标识及显示调度；帧间理论时间虽足够，控制与验证成本较高。新 DOA 核独立，显示不争夺输入、RAM、FFT 状态或输出，不增加显示帧调度延迟。唯一共同项是原有 50 MHz 时钟和音频来源。

**DC/低频**：dc_block 已实现 y=x-x1+y1-(y1>>>6)，约 120 Hz；默认 speech_band 150–6000 Hz，抗风 300–4000 Hz、窄带 300–3400 Hz。没有重复增加 HPF；PHAT 另外屏蔽 DC。原 PL 降噪仍为滤波/阵列，FFT 显示没有参与降噪。

**有效性与保持**：每对两通道帧能量都≥ENERGY_MIN；实峰≥2048 Q14（0.125），峰不在 ±8 外缘；任意非邻近正峰≤主峰的 75%；主峰/整个搜索窗口平均绝对幅值≥3；两条平行边的 Q4 差≤16。quality 保持已有 5 位接口，输出 31（通过）或 0（拒绝），不是标定后的连续 confidence 或语音 VAD。拒绝时 valid=0、update=1、frame_seq 增长，raw/filtered 方向保持；PS 公布的是 accepted，即算法有效且通过原几何门限。

**坐标与角度**：这是四麦 360° 平面方位，不适用双麦 asin 公式。0° 前、90° 右、180° 后、270° 左；b 比 a 滞后 +7 sample 时延迟为 +112 Q4，x>0,y=0 对应 270°。采用负 IFFT 索引已通过正负延迟测试，避免左右镜像。Q4 X/Y 直接参与 atan2，比值中共同的 /16 和 /Fs 抵消。没有 asin 域需要 clamp；零长度/不合理长度被 tracker 拒绝，避免 atan2(0,0) 被误认为有效方位。平面阵列不能区分相同水平投影的上下方声源。现有 IIR 平滑的是 X/Y，不是直接滤波 0..359°，避免跨 359°/0° 的环绕问题。

## E. 定点格式、归一化与溢出检查

| 节点 | signed 位宽 | 小数位/缩放 |
|---|---:|---|
| INMP441 ADC/I2S、HPF/增益/带通输出 | 24 | PCM 整数，F=0；带通内部另有 4 位小数 |
| DOA/FFT 输入 | 16 | F=0，取 24-bit PCM[23:8]，舍去 8 LSB |
| FFT twiddle | 16 | Q1.15；正逆变换改变正弦符号 |
| FFT 输出 Re/Im | 各16 | F=0，每级 /2，9 级合计 FFT/512；每级 signed 饱和 |
| 复乘的单个乘积 | 32 | F=0 |
| 互谱 Re/Im | 各33 | F=0，FFT 缩放后的频谱计数平方；两项加减先显式符号扩展 |
| PHAT abs | unsigned33 | 含 signed 极小数的绝对值 |
| PHAT 分母/余数 | unsigned35 | max+min/2+epsilon；试减使用 36 位左移结果 |
| PHAT 输出 | Re/Im 各16 | Q2.14，归一化绝对值<1；商 14 位小数，无浮点 |
| IFFT 输出/相关峰 | Re/Im 各16 | Q2.14，9 级 /2 得 IFFT/512；搜索使用 signed 实部 |
| Q4 delay | 9 | F=4，两个平行边求和/差先扩展 signed10 |
| 插值中间量 | signed/unsigned21 | 峰相邻差×8 和曲率先扩展，最多 8 次减法，分母0时 delta=0 |
| tracker 内部 | signed16 累加、signed17 更新 | 在输入 Q4 之上再保留 6 位小数 |
| 角度 | PS double 运算→int | atan2 的浮点仅用于原 PS 角度显示，不在 PL PHAT；整数度 0..359 |

幅值近似是资源/精度折中。max+0.5min 从不低估欧氏范数，最大相对高估 sqrt(1.25)-1≈11.8034%，因此不会把分量异常放大；epsilon=64 是 FFT 计数平方单位的正则项，不是声压或固定 SNR。极小 bin 直接抑制，防止量化噪声被 PHAT 放大。两个分量用并行串行恢复除法，每 bin 14 个周期，只有移位、比较、减法，无 sqrt、浮点除法器、倒数 LUT 或 Newton-Raphson。处理整帧后仍有充分预算，故不用大组合除法器。

16-bit 输入平方的上界 2^30，512 点能量≤2^39，signed48/unsigned48 安全；互谱33、分母35、试减36 位有余量；17 个 signed16 峰绝对值之和≤557056，21 位累计安全。旁瓣比较先 sign-extend 到19 位再乘 4/3；插值 delta 四舍五入且钳制 ±0.5 sample。FFT 每级算术右移会产生弱信号量化误差，PHAT epsilon/能量门限及 invalid 避免报告不可靠方向，但不承诺 Q4 格点等于物理精度。没有窗函数、频谱插值、额外零填充；当前是 512 点循环 GCC，有限帧边界与反射仍会影响结果。

invalid 行的延迟和角度是保持值，不计算相对于静音/独立噪声的“真实方向误差”。模拟噪声是确定性伪随机序列，11 帧只含互不相同的噪声片段全部拒绝，不能据此声称所有噪声场景零误报。弱反射是每麦不同的 11/13/17/19 点后 1/4 幅度副本；有噪声场景每路添加不同序列的 1/8 幅度副本。幅度不等为 mic1/mic2 降至 0.5。

7.125 点案例用于接近 7.1178 点物理上限的 Q4 测试，额外 0.0072 点位于工程余量内；用线性混合构造的延迟不是理想 sinc 分数延迟，实测 7.0 点，误差 -0.125 点，不将 1/16 格点宣称为实际精度。3.5/2.5 点案例估计准确。

联合链路 tb_doa_gcc_band：四档各四帧，期望 (3,6) 点；稳定帧结果 x=47..48、y=95..96 Q4，最多 1/16 点误差；窄带首帧 invalid、后续三帧有效。所有 clip/band_overrun/doa_overrun 都为0。连续实际间隔 1024 clock/sample 的三帧测试通过；人工以 2 clock/sample 输入三帧制造 overrun，断言采集 bank≠计算 bank，第一帧仍为 (3,2) 点且 valid=1，后两帧丢弃。

另通过原 64 点互相关回归、FFT 显示 impulse/bin16、tracker 几何/中值/符号收敛，以及 I2S、波束、音效、TMDS、AXI 控制、输出调理和录音环形缓存回归。DOA 的唯一 delay 来源是对 PHAT 谱做 IFFT 后的峰，未回退到时域相关（只有显式 GCC_PHAT=0 才选择 legacy）。

**延迟**：frame_time=512/Fs=10.48576 ms；一帧执行 4 FFT+4 IFFT，蝶形共 73728 clocks≈1.47456 ms；采集加载与频谱保存共8192 clocks≈0.16384 ms；复乘/归一化/PHAT 写入约3.64万 clocks≈0.728 ms；搜索/插值/置信度/发布为剩余约数百 clocks。测得非静音计算约11.89万 clocks≈2.378 ms，静音约9.03万 clocks≈1.807 ms；从帧首样本到 raw DOA 约12.86 ms（另外含原前级采样流水线的几十 μs）。计算小于一帧的 10.486 ms，双缓冲正常实时工作。角度在原 PS 任务中计算，PS 调度/HDMI 刷新不在该 RTL 延迟测量内。中值需三帧历史，默认 IIR 有数帧跟踪过渡，不能把 raw 延迟称为最终角度响应时间。
